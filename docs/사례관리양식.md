# 사례관리 참고 양식

`사례관리양식` 폴더의 HWP 12개를 참고해 서류 템플릿 14종을 추가했습니다.
기존 기본 양식 13종을 제거하고 이 14종만 제공합니다. `05_욕구조사표.hwp`의 기본·노인·장애인
서식은 각각 선택할 수 있도록 분리했습니다.

소스 실행 시 기존 사용자에게도 새 기본 양식이 자동으로 추가됩니다.
`데이터 관리 → 서류 양식`에서 `사례관리양식` 분류의 양식을 선택해 편집하거나,
상담 작성실의 서식 선택에서 사용하세요. 이전 기본 양식의 개인 사본은 목록에서 제거하며
DB의 `retired_form_templates` 테이블에 복구용으로 보관합니다.
직접 만든 사용자 양식과 이미 작성한 상담기록·양식 스냅샷은 유지됩니다.

이용신청서, 개인정보 동의서, 초기상담지, 과정기록지, 욕구조사표 3종,
서비스 제공계획 및 점검표, 종결평가서, 사후관리평가서, 서비스의뢰서,
평가보고서, 사례회의록, 상담일지를 포함합니다.

원본의 항목과 표 구조를 앱에서 편집 가능한 HTML로 재구성했습니다.
한글 원본의 페이지 배치·글꼴·도형을 그대로 복제하는 방식은 아닙니다.
가계도·생태도·약도·사진 항목에는 설명 또는 첨부 정보를 기록합니다.
반복표는 첫 행에 AI 결과를 입력하고 여러 항목은 셀 안에서 줄바꿈합니다.
나머지 빈 행은 직접 작성할 수 있습니다. 표 행·열은 양식 편집기에서 추가할 수 있고, AI를 사용할 경우 해당 입력칸 이름도
AI 작성 지침에 추가하세요.

원본 평가보고서와 사례회의록에 있던 사례 내용, 담당자 이름, 날짜 및 점수는
복사하지 않았습니다. 개인정보 동의서는 제공된 원본 안내 문구를 바탕으로
구성했으며 법령의 최신성 검토를 수행한 것은 아닙니다. 동의 여부와 서명·날인은
자동 입력 대상에서 제외하여 직접 작성하도록 했습니다.

구현은 `case_form_templates.py`에서 관리합니다. HWP 파일을 실행 시 읽지 않으므로
별도 한글 프로그램이나 HWP 파서가 필요 없습니다. 기존에 빌드한 EXE 및 설치파일에
반영하려면 새 소스로 재빌드해야 합니다.
