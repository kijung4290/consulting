# Windows / Linux 설치 · 1.1.0

14종 사례관리양식, 단계별 서류 작성·이력·임시저장·PDF 기능을 포함합니다.
최초 실행 시 데이터 저장 폴더를 선택하세요. 업데이트 전 전체 백업을 만들고
업데이트 후 같은 데이터 폴더를 선택하면 기존 기록을 계속 사용할 수 있습니다.
설치 파일에는 개발 PC의 config.json, 상담 DB, 첨부 서류를 포함하지 않습니다.

## Windows

WelfareAI-Setup-1.1.0.exe를 실행합니다. 기본 위치는 현재 사용자 계정의
AppData/Local/Programs이며 관리자 권한 없이 설치할 수 있습니다.
기존 앱을 종료하고 설치하세요. 기존 설치 AppId를 유지합니다.

배포 빌드는 Python 가상환경에 requirements.txt와 PyInstaller를 설치하고
Inno Setup 6 설치 후 다음 명령을 사용합니다.

```powershell
.\.venv\Scripts\python.exe build_package.py --platform all
```

결과는 installer_output/버전-빌드시각/에 생성됩니다. 이전 빌드는 보존됩니다.

## Linux Mint / Ubuntu

Linux 배포물은 소스와 설치 스크립트 묶음입니다. 그래픽 데스크톱 환경에서
압축을 사용자에게 쓰기 권한이 있는 폴더에 풀고 실행합니다.
Python 패키지를 설치하므로 최초 설치에는 인터넷 연결이 필요합니다.

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip build-essential cmake libgl1 libegl1 libxkbcommon-x11-0 libxcb-cursor0 libxcb-xinerama0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 fonts-nanum
cd WelfareAI
bash install_linux.sh
bash run_linux.sh
```

설치 실패 시 오류를 해결하고 install_linux.sh를 다시 실행합니다.
업데이트 시 소스를 교체하고 설치 스크립트를 다시 실행하세요.
실행할 때마다 sudo나 패키지 설치를 수행하지 않습니다.
Linux 가상환경 .venv_linux는 Windows .venv와 별도로 관리됩니다.

모델이 포함된 배포물은 모델을 다시 받을 필요가 없습니다. GitHub 소스에는
모델이 없으므로 앱의 모델 다운로드 기능을 사용하거나
models/gemma-2-2b-it-Q4_K_M.gguf를 별도로 넣어 주세요.
