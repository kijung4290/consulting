# 서류 수정·삭제

서류보관함에서 행을 선택하고 `선택 서류 수정` 또는 `서류 삭제`를 누릅니다.

| 종류 | 수정 가능한 내용 |
| --- | --- |
| 첨부 TXT | 제목, 서류 구분, 비고, 본문, 첨부 파일 교체 |
| 첨부 PDF·HWP·이미지 등 | 제목, 구분, 비고, 수정한 파일로 교체 |
| 상담일지 | 제목, 상담일자, 작성자, 표 서식이 포함된 본문 |
| 사례관리 서류 | 작성 당시 양식의 항목, 기록일, 작성 상태 |

상담일지와 사례관리 서류는 본인이 작성한 기록을 수정·삭제할 수 있습니다.
작성자 정보가 없는 이전 상담 기록도 수정할 수 있습니다.
사례관리 서류는 `작성완료` 상태여도 작성자가 다시 열어 수정할 수 있습니다.
다른 작성자의 사례 서류는 열람만 가능합니다.

수정은 같은 기록에 반영되므로 새 서류가 중복 등록되지 않습니다. 업무현황의 최근
서류 목록에 수정일을 반영하며 AI 맥락은 자동 재생성 대상으로 표시합니다.
수정한 상담 본문은 담당자가 직접 작성·확인한 내용으로 맥락에 반영합니다.
원래 양식 스냅샷과 대상자 연결은 유지합니다.

삭제는 확인창에서 동의한 경우 원본 기록을 삭제합니다. 첨부 파일은 다른 등록
서류가 같은 파일을 참조하지 않을 때 삭제합니다. 삭제 후 복구하려면 기존 백업이
필요합니다. 새 파일 교체가 실패하면 기존 기록과 파일은 유지합니다.
