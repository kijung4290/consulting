# 사례관리 서류 진행

사례관리 메뉴에서 대상자를 선택하면 첫 탭에 현재 단계의 서류가 표시됩니다.
접수·사정·계획·개입·점검·종결·사후관리 단계와 14종 양식을 연결했습니다.
단계 필터에서 전체 서류를 선택하면 단계와 관계없이 작성할 수 있습니다.
단계 이동은 담당자가 직접 저장하며 서류 작성완료와 자동으로 연동하지 않습니다.

- 새로 작성: 동일 양식의 새 기록을 추가합니다.
- 선택 이력 열기·이어쓰기: 하단 이력에서 선택한 기록을 엽니다.
- 임시저장 / 작성완료: 대상자와 작성자에 연결해 입력 내용과 양식 사본을 저장합니다.
- 이전 내용 불러오기: 이 대상자의 이전 서류를 선택해 같은 항목명의 빈칸에 반영합니다.
  날짜·작성자·동의·서명은 복사하지 않습니다. 의미가 다른 항목을 추측해 연결하지 않습니다.
- 인쇄 미리보기 / PDF 저장: 입력 내용을 해당 서류에 배치하여 출력합니다.

작성 창은 닫기·Esc 시 미저장 변경사항을 확인합니다. 다른 작성자의 서류는 열람만 가능합니다.
작성완료는 결재·서명 확인을 뜻하지 않으며 개인정보 동의서 서명은 출력 후 직접 작성합니다.
내용 입력의 반복 항목은 같은 순서로 줄바꿈합니다. 목표·가족·서비스별 동적 행 입력,
AI 초안의 사례 서류 직접 저장, 서명본 첨부 상태, 평가 자동 집계는 아직 지원하지 않습니다.

보조 업무 탭의 미저장 입력은 앱을 사용하는 동안 대상자별로 기억하며 재시작 후 유지되지 않습니다.
영구 보관하려면 각 탭의 저장 버튼을 사용하세요. 기존 상담기록·사정·계획·일정은 유지됩니다.
새 서류 이력은 `case_form_records`에 별도로 저장하고 이 화면에서 조회·PDF 출력합니다.
기존 상담일지 조회 창에는 합쳐 표시하지 않습니다. 전체 DB 백업에는 함께 포함됩니다.

코드: `case_forms.py`는 단계 매핑·작성 화면, `case_management.py`는 작업판 연결,
`database.py`는 대상자별 서류 저장을 담당합니다. 소스로 실행하면 필요한 테이블이 생성됩니다.
기존 EXE·설치파일은 재빌드해야 반영됩니다.
